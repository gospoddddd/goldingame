# Research Game Market

Use current primary sources whenever a product, price, policy, feature, or market condition could have changed.

## Workflow

1. Define the decision the research must support.
2. Select a small comparison set and explain the selection.
3. Observe the product directly when possible. Record the URL, access date, platform, and exact surface observed.
4. Capture comparable fields: audience, core action, daily or practice loop, session length, feedback, sharing, progression, account gate, monetization, data or media use, and visible operational burden.
5. Separate:
   - observation supported by a source;
   - inference from observations;
   - hypothesis that requires user evidence.
6. Compare patterns in a table only when the same fields are available.
7. Translate findings into differentiated opportunities and experiments, not feature copying.
8. Store the result using `vault/90 Templates/Research Note.md`; link facts and hypotheses to their canonical notes.

## Quality bar

- Never infer popularity, retention, revenue, or causal impact from the presence of a feature.
- Do not quote marketing copy as an independent fact.
- Prefer multiple source types for material decisions.
- Flag inaccessible, authenticated, stale, or ambiguous evidence.
- Include a revisit date for time-sensitive findings.
