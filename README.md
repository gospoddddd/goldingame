# Redraft

Рабочее пространство `goldingame` для подготовки платформы коротких баскетбольных игр. `Redraft` — временное название продукта, а концепция пока находится на стадии discovery.

## Где что находится

- `vault/` — Obsidian-хранилище и долговременная память проекта.
- `.codex/agents/` — роли специализированных агентов.
- `.agents/skills/` — повторяемые рабочие процессы.
- `.codex/config.toml` — локальные разрешения внутри репозитория.
- `.github/` — CI-проверка и шаблон pull request.
- `AGENTS.md` — постоянные правила работы Codex с проектом.
- `CONTRIBUTING.md` — workflow будущей команды.
- `Makefile` — стабильные project-level проверки.

## Начало работы

1. Открыть папку `vault/` как отдельное хранилище Obsidian.
2. Начать с `00 Home/Project Home.md`.
3. Перед разработкой согласовать открытые решения из `00 Home/Current Context.md`.
4. После изменений конфигурации или vault запустить `make check`.

Codex также запускает эту проверку через project Stop hook. После первого открытия проекта hook нужно просмотреть и подтвердить в `/hooks`.

Кодовый стек будет выбран отдельным ADR после проверки продуктового MVP и требований к данным.
