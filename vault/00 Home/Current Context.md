# Current Context

## Сейчас истинно

- Проект находится на стадии discovery; кодовый стек и флагманская игра не выбраны.
- Goldingame проектируется как платформа нескольких competitive-игр, а не как одна игра; сначала проверяется один флагман.
- Целевая направленность — увлечённые фанаты NBA, а не casual sports audience.
- Портфель должен включать игры о текущем сезоне и истории NBA; для каждой игры нужен собственный рейтинг.
- Для каждой игры приняты два слоя прогрессии: долгосрочный skill rating и сезонная лига.
- Queue-based 1v1 является обязательной целевой возможностью платформы, но может быть отложен после первого MVP; асинхронный challenge-response не является выбранной моделью.
- В каждой игре используется единый мировой рейтинговый пул для русской и английской версий при эквивалентных данных, seed и сложности; основные представления — мировой рейтинг, друзья и текущий сезон.
- Планируется web-first `.com` с русской и английской локализациями; доступность и владение конкретным доменом ещё не подтверждены.
- Созданы project-scoped роли агентов, навыки, правила репозитория и Obsidian vault.
- Codex имеет полный локальный read/write-доступ внутри папки проекта; внешние действия требуют отдельного подтверждения.
- OpenAI Developer Docs MCP включён; остальные интеграции подключаются поэтапно после появления конкретной системы-источника.
- Зафиксированы workflow для экспериментов, daily content packs и readiness review, а также proposed engineering quality strategy.
- Создан публичный GitHub-репозиторий `gospoddddd/goldingame`; bootstrap объединён в `main` через PR #1.
- GitHub Actions workflow `Workspace Quality` успешно выполняет обязательную проверку `Validate project configuration`.
- `main` защищён: изменения проходят через PR, required check должен быть актуален, обсуждения закрыты, force-push и удаление запрещены; правила действуют и для администратора.
- Владелец разрешил Codex самостоятельно выполнять branch, push и PR lifecycle, включая merge после успешных проверок; production, публикации, расходы и опасные изменения остаются за отдельным подтверждением.
- До отдельного review продукт считается самостоятельной generic-basketball платформой без официальных логотипов, фото, видео и неразрешённых источников данных.

## Принято

- Vault — долговременная память проекта; чат не является источником истины.
- Код и тесты будут источником истины для реализованного поведения.
- Сначала проверяется одна флагманская игровая петля, затем рассматривается портфель игр.
- Competitive progression следует [[../50 Decisions/ADR-0003 Competitive progression model|ADR-0003]].
- `make check`, project validator, Stop hook и будущий required CI являются единым repository quality contract ([[../50 Decisions/ADR-0002 Repository governance|ADR-0002]]).

## Открытые решения

1. Порядок запуска русского и английского языков и первая география привлечения внутри международного `.com`.
2. Первый competitive-формат MVP и момент добавления queue-based 1v1.
3. Первая игровая концепция и критерии её go/no-go.
4. Допустимое использование реальных игроков, команд, статистики и медиа.
5. Источник данных и бюджет на лицензию.
6. Модель регистрации, возраста, приватности и монетизации.
7. Технологический стек после уточнения MVP.
8. Точный `.com`-домен и проверка доступности названия Goldingame.

## Активные риски

## Следующий шаг

Сформировать три кандидата игровой петли и выбрать прототип для недельного теста; 1v1 не блокирует этот тест.
